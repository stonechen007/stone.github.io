方法1：运行一键修复脚本（推荐）

  cd /Users/shishengchen/promotion/stone.github.io
  ./一键修复.sh

这个脚本会：
✓ 自动修复所有权限问题
✓ 安装Python 3.11

✓ 让您立即能使用完整功能

方法2：手动修复（1分钟）
------------------------------------
在终端中依次执行：

  # 1. 修复Docker目录权限（需要输入密码）
  sudo chown -R $(whoami) /usr/local/lib/docker

  # 2. 安装Python 3.11
  brew install python@3.11

  # 3. 安装AkShare
  pip3 install akshare pandas openpyxl

  # 4. 运行脚本
  cd /Users/shishengchen/promotion/stone.github.io
  python3 fetch_glass_futures_akshare.py

❓ 常见问题

Q: 为什么会出现这个错误？
A: Docker安装时创建了root权限的目录，导致Homebrew无法访问

Q: 修复权限安全吗？
A: 完全安全。我们只是改变目录所有者为当前用户

Q: 不想修复可以吗？
A: 可以！使用pyenv或Anaconda，或者暂时用演示版本
