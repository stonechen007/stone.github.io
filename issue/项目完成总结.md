### 高级用法

#### 修改获取天数

打开脚本文件，找到并修改：

```python
# 原来（获取10天）
df = fetch_glass_futures_data(days=10)

# 修改为（获取30天）
df = fetch_glass_futures_data(days=30)
```

#### 定时自动运行

使用crontab设置定时任务：

```bash
# 编辑定时任务
crontab -e

# 添加以下行（每天9点运行）
0 9 * * * cd /Users/shishengchen/promotion/stone.github.io && python3 fetch_glass_futures_akshare.py
```

#### 批量处理多个期货品种

修改脚本中的品种代码：

```python

df = ak.futures_zh_daily_sina(symbol="FG0")
```

## 📞 常见问题

### Q1: 运行脚本提示"未安装xxx库"？

**A**: 安装对应的依赖库：
```bash
pip3 install akshare pandas requests
```

### Q2: 获取不到数据？

**A**: 可能的原因：
1. 网络连接问题
2. API接口变更
3. 数据源暂时不可用

解决方案：
- 检查网络连接
- 尝试其他版本的脚本
- 稍后重试

### Q3: Python版本太低？

**A**: 查看版本并升级：
```bash

```
