## 🚀 快速开始

### 第一步：体验演示（无需安装任何东西）

```bash
# 直接运行演示脚本
python3 fetch_glass_futures_demo.py
```

运行后会：
- 在屏幕上显示模拟的期货数据表格
- 生成 `glass_futures_demo.csv` 文件（可用Excel打开）
- 生成 `glass_futures_demo.txt` 文本文件

### 第二步：获取真实数据

#### 方法1：使用AkShare（最简单，推荐）

```bash
# 1. 检查Python版本（必须是3.8或更高）
python3 --version

# 2. 安装需要的库
pip3 install akshare pandas openpyxl

# 3. 运行脚本获取真实数据
python3 fetch_glass_futures_akshare.py
```

#### 方法2：使用API（如果Python版本是3.7）

```bash
# 1. 安装需要的库
pip3 install requests pandas

# 2. 运行脚本
python3 fetch_glass_futures.py
```

## 📊 获取的数据内容

脚本会抓取玻璃主连期货（FG0）最近10天的以下信息：

| 数据项 | 说明 |
|--------|------|
| 日期 | 交易日期 |
| 开盘价 | 当天开盘时的价格 |
| 收盘价 | 当天收盘时的价格 |
| 最高价 | 当天的最高价格 |
| 最低价 | 当天的最低价格 |
| 最高最低价差 | 当天最高价和最低价的差值 |
| 成交量 | 交易的手数 |
| 成交额 | 交易的总金额 |

## 📁 生成的文件

运行脚本后会生成：

- **CSV文件**：可以用Excel打开的表格文件
- **Excel文件**：AkShare版本会额外生成.xlsx文件
- **控制台输出**：直接在屏幕上显示数据和统计信息

## 💡 常见问题

### 问：我的Python版本太低怎么办？

**答**：查看当前版本：
```bash
python3 --version
```

- 如果是 3.8 或更高：使用 `fetch_glass_futures_akshare.py`
- 如果是 3.7：使用 `fetch_glass_futures.py`
- 如果低于 3.7：建议升级Python

### 问：安装依赖包很慢或失败？

**答**：使用国内镜像加速：
```bash
pip3 install akshare pandas -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问：如何获取更多天数的数据？

**答**：打开脚本文件，找到这一行：
```python
df = fetch_glass_futures_data(days=10)
```
改成：
```python
df = fetch_glass_futures_data(days=30)  # 获取30天
```

### 问：如何每天自动运行？

**答**：可以使用系统的定时任务功能。在macOS上：
```bash
# 编辑定时任务
crontab -e

# 添加以下内容（每天早上9点运行）
0 9 * * * cd /Users/shishengchen/promotion/stone.github.io && python3 fetch_glass_futures_akshare.py
```
