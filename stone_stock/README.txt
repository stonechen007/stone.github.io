🎯 工具介绍
================================================================================

自动筛选符合特定条件的A股股票：
  • 最近N天连续上涨
  • 成交量连续N天增长≥X%

================================================================================
📁 文件列表
================================================================================

核心脚本：
1. filter_rising_stocks.py              - 标准版（价格上涨+成交量增长）
2. filter_rising_stocks_advanced.py     - 增强版（价格上涨+成交量增长，可调参数）
3. filter_volume_surge.py               - 成交量版（只看成交量增长）⭐新增

文档说明：
4. 股票筛选工具说明.md                  - 连续上涨版详细文档
5. 股票筛选快速指南.txt                 - 连续上涨版快速参考
6. 成交量放大筛选说明.md                - 成交量版详细文档⭐新增
7. 成交量筛选快速指南.txt               - 成交量版快速参考⭐新增
8. 错误修复说明.txt                     - 错误修复记录
9. README.txt                           - 本文件（总览）

================================================================================
🎯 三种工具对比
================================================================================

1️⃣ filter_volume_surge.py （成交量放大版）⭐推荐新手
   条件：成交量连续N天增长≥X%
   特点：只看量，不看价
   适合：发现资金异动、潜在热点
   
2️⃣ filter_rising_stocks_advanced.py （连续上涨增强版）⭐推荐进阶
   条件：价格连续上涨 + 成交量增长
   特点：量价齐升，可调参数
   适合：寻找强势股、确定性机会
   
3️⃣ filter_rising_stocks.py （连续上涨标准版）
   条件：固定3天上涨 + 15%成交量增长
   特点：参数固定，简单易用
   适合：日常快速扫描

================================================================================
⚡ 快速开始
================================================================================

# 成交量放大版（推荐先用这个）
python3.11 filter_volume_surge.py -n 50

# 连续上涨增强版
python3.11 filter_rising_stocks_advanced.py -n 50

# 连续上涨标准版
python3.11 filter_rising_stocks.py

查看帮助:
  python3.11 filter_volume_surge.py -h
  python3.11 filter_rising_stocks_advanced.py -h

================================================================================
🔧 命令行参数
================================================================================

-d, --days      连续上涨天数（默认3）
-v, --volume    成交量增长阈值%（默认15）
-n, --number    扫描股票数量（默认全部）
-o, --output    输出文件名（默认qualified_stocks）

  • qualified_stocks.csv  - CSV格式
  • qualified_stocks.xlsx - Excel格式

查看结果：
  open qualified_stocks.xlsx

🆘 故障排除
================================================================================

问题1: TypeError 错误
  ✅ 已修复，重新下载最新版本

问题2: 未找到符合条件的股票
  • 扩大扫描范围（增加-n参数）
  • 放宽条件（降低-d或-v参数）
  • 尝试不同时间段运行

问题3: 运行太慢
  • 减少扫描数量
  • 使用测试模式（-n 50）
  • 检查网络连接

问题4: 导入错误
  • 检查 Python 版本: python3.11 --version
  • 安装 AkShare: pip3.11 install akshare pandas openpyxl
  • 更新 AkShare: pip3.11 install --upgrade akshare

💡 使用示例
================================================================================

推荐工作流（组合使用）:

第一步：成交量筛选（发现候选股票）
  python3.11 filter_volume_surge.py -n 500 -o volume
  说明：找出所有成交量放大的股票

第二步：连续上涨筛选（发现强势股票）
  python3.11 filter_rising_stocks_advanced.py -n 500 -o rising
  说明：找出价格上涨+成交量放大的股票

第三步：对比分析
  open volume.xlsx rising.xlsx
  说明：两者都出现的重点关注！

----

单独使用场景：

成交量版 - 寻找潜在热点
  python3.11 filter_volume_surge.py -d 2 -v 10 -n 500

成交量版 - 寻找异常放量
  python3.11 filter_volume_surge.py -d 3 -v 25 -n 1000

连续上涨版 - 快速找强势股
  python3.11 filter_rising_stocks_advanced.py -d 2 -v 10 -n 500

连续上涨版 - 寻找超强势股
  python3.11 filter_rising_stocks_advanced.py -d 4 -v 20 -n 1000
