# 股票筛选工具 - 成交量放大版

## 🎯 工具特点

### 与其他版本的区别

| 版本 | 筛选条件 | 适用场景 |
|------|---------|----------|
| **连续上涨版** | 价格连续上涨 + 成交量增长 | 寻找强势上涨股 |
| **成交量放大版** | 只看成交量增长 | 捕捉资金异动 ⭐本工具 |

### 核心特点

✅ **只关注成交量** - 不限制价格涨跌  
✅ **捕捉资金流向** - 发现大资金进场信号  
✅ **提前布局** - 可能在拉升前发现机会  
✅ **包容性强** - 上涨、下跌、横盘都可能筛出

---

## 📊 筛选逻辑

### 默认条件
- 最近**3天**成交量**连续增长≥15%**
- 不限制价格变化方向

### 适合寻找
1. 🔥 **潜在热点** - 资金提前布局
2. 📈 **底部放量** - 可能筑底完成
3. 💰 **机构进场** - 大资金建仓信号
4. 🎯 **突破前兆** - 放量可能预示突破

## 🔧 命令行参数

```bash
python3.11 filter_volume_surge.py [参数]

参数：
  -d, --days      成交量连续增长天数（默认3）
  -v, --volume    成交量增长阈值%（默认15）
  -n, --number    扫描股票数量（默认全部）
  -o, --output    输出文件名（默认volume_surge_stocks）

示例：
  -d 3          # 3天连续成交量增长
  -v 15         # 每天增长≥15%
  -n 500        # 扫描前500只股票
  -o result     # 保存为result.csv
```

## 🔍 结果分析技巧

### 1. 按成交量增长排序

Excel中按"平均成交量增长(%)"降序排列，找出放量最明显的股票。

### 2. 价格走势分类

| 价格走势 | 可能含义 | 关注度 |
|---------|---------|--------|
| **上涨+放量** | 强势股，资金追捧 | ⭐⭐⭐⭐⭐ |
| **横盘+放量** | 可能筑底，蓄势待发 | ⭐⭐⭐⭐ |
| **下跌+放量** | 可能止跌，也可能出货 | ⭐⭐⭐ |

### 3. 成交量增长幅度

| 增长幅度 | 解读 |
|---------|------|
| 15-25% | 正常放量 |
| 25-50% | 明显放量 ⭐ |
| >50% | 异常放量 ⭐⭐ |

### 4. 结合K线图分析

筛选出来后，建议：
1. 查看K线图形态
2. 观察成交量柱状图
3. 关注MACD等技术指标
4. 查看基本面消息

## ⚠️ 风险提示

### 注意事项

1. **成交量放大≠必然上涨**
   - 可能是出货
   - 可能是对倒
   - 需要结合其他因素判断

2. **不同场景不同解读**
   - 高位放量：警惕出货
   - 低位放量：可能是机会
   - 横盘放量：可能突破

3. **数据仅供参考**
   - 不构成投资建议
   - 需要综合分析
   - 控制仓位风险

## 🆘 常见问题

### Q1: 为什么有些下跌的股票也出现在结果中？

**A:** 这是正常的！成交量放大不代表必然上涨：
- 可能是恐慌性抛售
- 可能是止跌信号
- 需要结合K线形态判断

### Q2: 如何筛选只上涨的股票？

**A:** 使用连续上涨版脚本：
```bash
python3.11 filter_rising_stocks_advanced.py -n 500
```

### Q3: 成交量放大有什么意义？

**A:** 成交量放大通常意味着：
- 💰 资金关注度提升
- 🔥 市场分歧加大
- 📈 可能产生趋势变化
- ⚠️ 需要结合价格走势判断

### Q4: 15%的阈值合适吗？

**A:** 取决于市场环境：
- 活跃市场：可提高到20-25%
- 冷清市场：可降低到10-15%
- 建议根据实际情况调整
