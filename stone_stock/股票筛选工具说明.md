# 股票筛选工具使用说明

## 📊 工具简介

自动筛选符合特定条件的A股股票，帮助发现潜在的强势股。

---

## 🎯 筛选条件

### 默认条件（严格模式）
1. **连续上涨**: 最近三天收盘价连续上涨
2. **成交量放大**: 成交量连续三天增长≥15%

这个条件组合可以筛选出：
- ✅ 价格持续走强
- ✅ 成交活跃度显著提升
- ✅ 可能存在资金持续流入

## 💡 使用技巧

### 1. 分批扫描

如果全量扫描时间太长，可以分批进行：

```python
# 修改脚本，指定股票范围
stock_list = stock_list[0:1000]    # 扫描前1000只
stock_list = stock_list[1000:2000] # 扫描第1000-2000只
```

### 2. 调整筛选条件

如果想放宽或收紧条件，可以修改脚本中的参数：

```python
# 在 check_conditions 函数中
# 修改成交量增长阈值（默认15%）
growth_rate >= 10  # 改为10%，条件更宽松
growth_rate >= 20  # 改为20%，条件更严格

# 修改连续天数（默认3天）
for i in range(1, 5):  # 改为4天
```

### 3. 查看中间结果

运行时会实时显示找到的股票：

## 🔧 常见问题

### Q1: 为什么没有找到符合条件的股票？

**原因：**
- 筛选条件严格（连续3天上涨+成交量增长≥15%）
- 样本量较小
- 当前市场环境不符合

**解决：**
- 扩大扫描范围（选择模式2或3）
- 适当放宽条件（修改成交量增长阈值）
- 尝试不同时间段运行

### Q2: 运行很慢怎么办？

**解决：**
- 使用测试模式（50只）先验证
- 分批扫描，避免一次性全量
- 检查网络连接

### Q3: 如何修改筛选条件？

**步骤：**
1. 打开 `filter_rising_stocks.py`
2. 找到 `check_conditions` 函数
3. 修改相关参数
4. 重新运行

### Q4: 数据准确吗？

**说明：**
- 使用公开的历史行情数据
- 采用前复权价格（考虑分红配股）
- 仅供参考，建议交叉验证

## 🎓 进阶功能

### 自定义筛选条件

创建自己的筛选逻辑：

```python
def my_custom_filter(df):
    """自定义筛选条件"""
    
    # 例如：3天涨幅超过10%且换手率>5%
    recent = df.tail(3)
    total_change_pct = ((recent.iloc[-1]['close'] - recent.iloc[0]['close']) 
                        / recent.iloc[0]['close'] * 100)
    
    avg_turnover = recent['换手率'].mean()  # 需要获取换手率数据
    
    return total_change_pct > 10 and avg_turnover > 5
```
