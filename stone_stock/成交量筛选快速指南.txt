🎯 工具特点
================================================================================

与连续上涨版的区别：
  
  连续上涨版：   价格连续上涨 + 成交量增长 → 强势股
  成交量放大版： 只看成交量增长 → 资金异动 ⭐本工具

核心特点：
  ✓ 只关注成交量，不限制价格涨跌
  ✓ 捕捉大资金进场信号
  ✓ 可能提前发现热点
  ✓ 包容性强（上涨、下跌、横盘都可能筛出）

适合寻找：
  🔥 潜在热点 - 资金提前布局
  📈 底部放量 - 可能筑底完成  
  💰 机构进场 - 大资金建仓
  🎯 突破前兆 - 放量预示突破

# 进入工作目录

================================================================================
🔧 命令参数说明
================================================================================

-d, --days      成交量连续增长天数（默认3）
-v, --volume    成交量增长阈值%（默认15）
-n, --number    扫描股票数量（默认全部）
-o, --output    输出文件名（默认volume_surge_stocks）

示例：
  -d 3          # 3天连续成交量增长
  -v 15         # 每天增长≥15%
  -n 500        # 扫描前500只股票
  -o result     # 保存为result.csv和result.xlsx

================================================================================
📊 三大工具对比
================================================================================

1. filter_volume_surge.py （成交量放大版）⭐本工具
   条件：成交量连续N天增长≥X%
   特点：只看量，不看价
   适合：发现资金异动
   
2. filter_rising_stocks_advanced.py （连续上涨版）
   条件：价格连续上涨 + 成交量增长
   特点：量价齐升
   适合：寻找强势股
   
3. filter_rising_stocks.py （标准版）
   条件：固定3天上涨 + 15%成交量增长
   特点：参数固定
   适合：日常扫描

建议组合使用：
  # 先用成交量版找潜在股票
  python3.11 filter_volume_surge.py -n 500 -o volume
  
  # 再用连续上涨版找强势股
  python3.11 filter_rising_stocks_advanced.py -n 500 -o rising
  
  # 对比分析，两者都出现的重点关注！

📈 结果分析技巧
================================================================================

1. 按成交量增长排序
   在Excel中按"平均成交量增长(%)"降序排列

2. 价格走势分类
   上涨+放量 → 强势股，重点关注 ⭐⭐⭐⭐⭐
   横盘+放量 → 可能蓄势，观察 ⭐⭐⭐⭐
   下跌+放量 → 可能止跌，谨慎 ⭐⭐⭐

3. 成交量增长幅度
   15-25%  → 正常放量
   25-50%  → 明显放量 ⭐
   >50%    → 异常放量 ⭐⭐

4. 结合K线图
   - 查看形态
   - 观察成交量柱
   - 关注技术指标
   - 查看基本面

⚠️ 重要提示
================================================================================

1. 成交量放大 ≠ 必然上涨
   • 可能是出货
   • 可能是对倒
   • 需要综合判断

2. 不同位置不同解读
   • 高位放量：警惕出货
   • 低位放量：可能机会
   • 横盘放量：可能突破

3. 数据仅供参考
   • 不构成投资建议
   • 需要综合分析
   • 控制仓位风险

================================================================================
🆘 故障排除
================================================================================

问题1：未找到符合条件的股票
解决：
  • 降低成交量阈值（-v 10）
  • 减少连续天数（-d 2）
  • 扩大扫描范围（-n 1000）

问题2：运行太慢
解决：
  • 减少扫描数量（-n 100）
  • 检查网络连接
  • 避开开盘时间

问题3：导入错误
解决：
  python3.11 --version  # 检查版本
  pip3.11 list | grep akshare  # 检查安装
  pip3.11 install --upgrade akshare  # 更新
