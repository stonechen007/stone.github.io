## 💡 使用建议

### 1. 价格对比分析

在Excel中：
1. 打开 `all_futures_by_variety.xlsx`
2. 选择多个工作表数据
3. 创建折线图对比价格走势

### 2. 涨跌幅对比

使用合并文件：
1. 打开 `all_futures_combined.xlsx`
2. 按品种分组
3. 计算各品种涨跌幅

### 3. 相关性分析

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.read_csv('all_futures_combined.csv')

# 透视表：日期 vs 品种的收盘价
pivot = df.pivot(index='日期', columns='品种', values='收盘价')

# 计算相关性
correlation = pivot.corr()
print(correlation)

# 可视化
sns.heatmap(correlation, annot=True)
plt.show()
```

### 4. 成交量分析

对比各品种的成交活跃度：
```python
df.groupby('品种')['成交量'].mean().sort_values(ascending=False)
```
