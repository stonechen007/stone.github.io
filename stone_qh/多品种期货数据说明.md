## 📊 数据来源

- **数据源**: 新浪财经
- **数据类型**: 主连合约（连续合约）
- **更新频率**: 每个交易日
- **历史数据**: 可获取完整历史

---

## ⚠️ 注意事项

1. **交易日数据**: 只有交易日才有数据，周末和节假日无数据
2. **主连合约**: 数据来自主力合约的连续数据
3. **价格单位**: 所有价格均为元/吨
4. **数据仅供参考**: 不构成投资建议

## 🆘 常见问题

### Q1: 如何获取更多天数的数据？

修改脚本中的 `days` 参数：

```python
data_dict = fetch_multiple_futures_data(days=30)  # 获取30天
```

### Q2: 如何添加更多品种？

在 `FUTURES_INFO` 中添加品种代码：

```python
FUTURES_INFO = {
    'MA0': {'name': '甲醇', 'unit': '元/吨'},
    'UR0': {'name': '尿素', 'unit': '元/吨'},
    'SA0': {'name': '纯碱', 'unit': '元/吨'},
    'FG0': {'name': '玻璃', 'unit': '元/吨'},  # 新增
    'RB0': {'name': '螺纹钢', 'unit': '元/吨'},  # 新增
}
```

### Q3: 数据获取失败怎么办？

1. 检查网络连接
2. 确认是交易日
3. 尝试更新AkShare: `pip3.11 install --upgrade akshare`

### Q4: 如何导入到数据分析工具？

**Python/Pandas:**
```python
import pandas as pd
df = pd.read_csv('futures_data_combined.csv')
```

**Excel:**
直接打开 `futures_data_combined.xlsx`
